# FoodWell
โปรเจกต์เว็บแอป FoodWell สำหรับบันทึกอาหาร น้ำ และการเคลื่อนไหว

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือเผยแพร่ด้วย GitHub Pages

## หมายเหตุ
ข้อมูลถูกเก็บไว้ใน localStorage ของเครื่อง/เบราว์เซอร์นั้น ๆ
ค่าพลังงานและโภชนาการเป็นค่าประมาณสำหรับการบันทึก ไม่ใช่เป้าหมายจำกัดการกิน

## Android
โปรเจกต์นี้เป็นเวอร์ชันเว็บที่พร้อมนำไปห่อเป็น Android WebView/Capacitor ต่อได้ แต่ยังไม่ได้สร้างไฟล์ APK ในเครื่องนี้
