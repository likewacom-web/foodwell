# FoodWell AI proxy (ฟรี: Gemini + Cloudflare Workers)

เซิร์ฟเวอร์ตัวกลางสำหรับปุ่ม **✨ วิเคราะห์รูป** ในหน้าเพิ่มอาหาร
แอปส่งรูปมาที่นี่ → ส่งต่อให้ Gemini → ตอบกลับชื่ออาหาร (ภาษาไทย) และค่าโภชนาการโดยประมาณ
API key เก็บไว้ที่ Cloudflare เท่านั้น ไม่ได้อยู่ในแอป

ทั้งสองบริการมีแพ็กเกจฟรี ไม่ต้องผูกบัตร (เงื่อนไขของผู้ให้บริการอาจเปลี่ยนได้)
หมายเหตุ: ในแพ็กเกจฟรี Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงบริการ

## 1. ขอ Gemini API key
1. เปิด https://aistudio.google.com/apikey แล้วล็อกอินด้วยบัญชี Google
2. กด **Create API key** แล้วคัดลอก key เก็บไว้

## 2. สร้าง Worker บน Cloudflare
1. สมัคร/ล็อกอินที่ https://dash.cloudflare.com
2. ไปที่ **Workers & Pages** → **Create** → เลือกเริ่มจาก **Hello World**
3. ตั้งชื่อ เช่น `foodwell-ai` แล้วกด **Deploy**
4. กด **Edit code** ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาไฟล์ [`worker.js`](./worker.js) แทน → กด **Deploy**

## 3. ใส่ key (ตั้งเป็น Secret)
ใน Worker ที่สร้าง → **Settings** → **Variables and Secrets** → **Add**

| ชื่อ | ประเภท | ค่า |
|---|---|---|
| `GEMINI_API_KEY` | Secret | key จากข้อ 1 |
| `APP_TOKEN` | Secret | ตั้งรหัสเองยาว ๆ เช่น `fw-8k2m9q` (กันคนอื่นแอบใช้โควตา) |
| `GEMINI_MODEL` | Text (ไม่ใส่ก็ได้) | ระบุรุ่นเอง ถ้ารุ่นเริ่มต้นใช้ไม่ได้ เช่น `gemini-2.5-flash` |

กด **Deploy** อีกครั้งหลังเพิ่มค่า

## 4. ตั้งค่าในแอป
1. คัดลอก URL ของ Worker เช่น `https://foodwell-ai.yourname.workers.dev`
2. ในแอป FoodWell → **เพิ่มเติม** → **🤖 AI Food Recognition** → ช่อง **AI Endpoint** ใส่
   `https://foodwell-ai.yourname.workers.dev/?k=รหัส-APP_TOKEN`
3. กด **บันทึก Endpoint**
4. ทดลอง: หน้า **อาหาร** → ถ่าย/เลือกรูป → **✨ วิเคราะห์รูป**

## ข้อความผิดพลาดที่อาจเจอ
- `token ไม่ถูกต้อง` → `?k=` ในแอปไม่ตรงกับ `APP_TOKEN`
- `ยังไม่ได้ตั้งค่า GEMINI_API_KEY` → ยังไม่ได้เพิ่ม Secret หรือยังไม่กด Deploy
- `ใช้เกินโควตาฟรีของ Gemini แล้ว` → รอให้โควตารีเซ็ต (ไม่มีการเก็บเงิน)
- `ไม่พบโมเดล ...` → ตั้ง `GEMINI_MODEL` เป็นรุ่นที่ยังเปิดใช้ (ดูรายชื่อใน AI Studio)

## รูปแบบ API
`POST` JSON `{ "image": "data:image/jpeg;base64,..." }`
ตอบกลับ `{ "name", "candidates", "confidence", "kcal", "protein", "carbs", "fat", "fiber", "sugar", "sodium", "model" }`

### บอกว่ากินอะไร (พิมพ์หรือพูด)
`POST /parse?k=<APP_TOKEN>` JSON `{ "text": "ข้าวมันไก่ 1 จาน ชาเย็น 1 แก้ว" }`
ตอบกลับ `{ "items": [{ "name", "qty", "meal", "kcal", "protein", "carbs", "fat", "fiber", "sugar", "sodium" }], "model" }`
ใช้ Gemini key เดียวกับการวิเคราะห์รูป ไม่ต้องตั้งค่าเพิ่ม แค่วางโค้ด `worker.js` ใหม่แล้วกด Deploy

## โค้ดเปิดใช้งานตัวเต็ม (ไม่บังคับ)
โค้ดแบบ `MEOW-ABCD-EFGH` จะเปิดตัวเต็มของแอป (ไม่มีโฆษณา + วิเคราะห์รูปด้วย AI ได้ไม่จำกัด) ตามจำนวนวันของโค้ด หรือแบบถาวร
- โค้ดหนึ่งตัวใช้ได้กับ**มือถือเครื่องเดียว** ถ้าเครื่องอื่นใส่โค้ดเดียวกัน จะขึ้นว่า "ถูกใช้กับเครื่องอื่นแล้ว"
- ถ้าเครื่องเดิมลงแอปใหม่ ใส่โค้ดเดิมได้ แอปจะคืนสิทธิ์ให้จนถึงวันหมดอายุเดิม
- ถ้าใส่โค้ดใหม่ขณะที่ยังมีเวลาเหลือ ระบบจะบวกจำนวนวันเพิ่มต่อจากเวลาที่เหลือ

### ตั้งค่าครั้งแรก
1. Cloudflare → **Storage & Databases** → **KV** → **Create** ตั้งชื่อ เช่น `meowfit-codes`
2. เข้า Worker → **Settings** → **Bindings** → **Add** → **KV namespace**
   ตั้ง Variable name เป็น `CODES` แล้วเลือก namespace ที่สร้างไว้
3. **Settings** → **Variables and Secrets** → **Add** → ประเภท **Secret** ชื่อ `ADMIN_TOKEN` แล้วตั้งรหัสยาว ๆ ที่เดายาก (ห้ามบอกใคร)
4. กด **Deploy**

### สร้างโค้ด
1. เปิด `https://<ชื่อ worker>.workers.dev/admin` บนมือถือหรือคอมพิวเตอร์
2. ใส่ `ADMIN_TOKEN` แล้วเลือกจำนวนวัน (7 / 30 / 90 / 180 / 365 วัน หรือถาวร) และจำนวนโค้ด
3. "ต้องใช้ภายใน" คือจำนวนวันที่ต้องกดใช้โค้ดก่อนโค้ดหมดอายุ ใส่ 0 ถ้าไม่จำกัด
4. กด **สร้างโค้ด** → **คัดลอกทั้งหมด** แล้วส่งให้ผู้รับ
5. กด **โหลดรายการ** เพื่อดูว่าโค้ดไหนถูกใช้แล้ว หรือกด **ยกเลิก** โค้ดที่ยังไม่อยากให้ใช้
   (การยกเลิกจะกันไม่ให้ใช้ได้ใหม่ แต่จะไม่ปิดสิทธิ์ที่เครื่องได้ไปแล้ว)

ผู้ใช้ใส่โค้ดในแอปที่ **ตั้งค่า → ข้อมูลและซิงก์ → การ์ดปิดโฆษณา → 🎟️ มีโค้ดเปิดใช้งาน?**

> ⚠️ นโยบายของ Google Play: แจกโค้ดฟรีได้ (เช่น ให้ผู้ทดสอบ ของรางวัล โปรโมชัน)
> แต่**ห้ามขายโค้ดนอก Google Play** เพื่อเปิดฟีเจอร์ในแอป การขายต้องใช้ระบบซื้อในแอปของ Google Play

### รูปแบบ API ของโค้ด
`POST /redeem?k=<APP_TOKEN>` JSON `{ "code": "MEOWABCDEFGH", "device": "<hash 32 ตัว>" }`
ตอบกลับ `{ "until": <ms, 0 = ถาวร>, "forever": bool, "days": n, "again"?: true }`
หรือ `{ "error": "..." }` พร้อมสถานะ 404 (ไม่พบ) / 409 (ใช้กับเครื่องอื่นแล้ว) / 410 (หมดอายุหรือถูกยกเลิก)
